# Your candidate profile

| File | Who writes it | Content |
|---|---|---|
| `cv-source.md` | **You** | Your current CV, or the text of your LinkedIn profile export (LinkedIn → your profile → More → Save to PDF, then copy the text). Real dates, employers, stack and results with numbers where you have them |
| `candidate.md` | `profile` | Consolidated profile: summary, skills, structured experience, quantified results, ATS keywords |
| `cv-base.md` | `profile` | One-page base CV every tailored CV starts from |
| `linkedin.md` | `profile` | Headline, About, Experience and Skills rewritten for recruiters |

**First step:** create `cv-source.md`. Nothing is invented: whatever is missing comes back as `[PENDING: …]` for you to fill in.
